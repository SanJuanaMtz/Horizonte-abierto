Las variables son una de las primeras cosas que vemos al empezar a programar, y aunque parecen simples, son la base de todo.

En Python, algo que cambia desde el inicio es que no necesitamos declarar el tipo de dato.

El lenguaje lo interpreta automáticamente a partir del valor que le asignamos.

Eso hace que escribir código se sienta más ligero.

Por ejemplo:


nombre="John"
edad=27
altura=1.75
es_estudiante=True

Después de trabajar con C, esto se siente como soltar un poco de control.

Ya no tengo que preocuparme por definir cada tipo desde el inicio, simplemente asigno el valor y Python se encarga del resto.

También podemos asignar un mismo valor a varias variables:


a=b=c=13

Y algo importante es cómo nombramos nuestras variables.

Pueden contener letras, números y guiones bajos, pero no podemos usar palabras reservadas como `if`, `else` o `while`.

Más allá de las reglas, algo que he notado es que elegir buenos nombres hace una gran diferencia.

Un nombre claro puede hacer que el código se entienda casi por sí solo.

Aunque este tema parece básico, volver a él me hizo darme cuenta de algo.

Muchos de estos conceptos no cambian entre lenguajes.

Siguen siendo la base.

La diferencia está en cómo cada lenguaje decide manejarlos.

Y en este caso, Python hace que todo se sienta un poco más simple… pero no por eso menos importante.
