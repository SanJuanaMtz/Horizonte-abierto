Cuando los caminos comienzan a conectarse

Cada ocasión en que aprendíamos un lenguaje nuevo me sentía un poco como Thanos al conseguir una gema nueva.

Cada lenguaje parecía abrir un camino diferente.

C.

Python.

SQL.

Cada uno tenía sus propias reglas, estructuras y maneras de resolver problemas.

Pero, de algún modo, esos caminos nunca estuvieron realmente separados.

Conforme seguí aprendiendo, comenzaron a aparecer conexiones entre ellos.

Ahora que estoy retomando SQL después de haber terminado Python, volver a encontrar esas conexiones y descubrir cómo cada lenguaje puede complementar al otro resulta todavía más emocionante.

Hace poco hablaba sobre combinar cosas.

Pues resulta que también podemos combinar lenguajes.

Así es como los caminos comienzan a encontrarse.

Python y SQL

Con SQL podemos trabajar con bases de datos, almacenar información y realizar consultas sobre ella.

Python, por otro lado, nos permite construir programas y automatizar tareas.

Cuando los combinamos, podemos utilizar Python como una herramienta para interactuar con una base de datos.

Durante el curso de CS50, por ejemplo, podemos hacerlo utilizando:


from cs50 import SQL

A partir de ahí podemos inicializar y manipular una base de datos desde nuestro programa de Python.

Esto me parece especialmente interesante porque cada lenguaje puede concentrarse en aquello para lo que resulta más conveniente.

No necesitamos que un solo lenguaje haga absolutamente todo.

Podemos permitir que cada uno aporte sus propias fortalezas.

¿Por qué utilizar una base de datos?

Python cuenta con estructuras de datos como listas, diccionarios y conjuntos, que son excelentes para trabajar con información mientras nuestro programa está en ejecución.

Pero estas estructuras no están pensadas para sustituir una base de datos.

Una lista puede guardar información mientras nuestro programa está funcionando, pero si cerramos el programa, esa información desaparece a menos que la hayamos almacenado en algún lugar.

Una base de datos nos permite conservar la información de manera persistente y, además, nos proporciona herramientas especializadas para consultarla, relacionarla, actualizarla y administrarla.

Es aquí donde ambos caminos comienzan a tener todavía más sentido.

Python puede encargarse de la lógica de nuestro programa.

SQL puede encargarse de trabajar con nuestros datos.

Y juntos pueden convertirse en algo mucho más grande que cualquiera de los dos por separado.

Las piezas comienzan a encajar

Quizás eso es lo que más me está gustando de retomar mi aprendizaje.

Al principio, cada lenguaje parecía una habitación diferente.

Ahora empiezo a descubrir las puertas que las conectan.

Y quizá aprender varios lenguajes no consiste en coleccionar herramientas, sino en entender **cuándo utilizar cada una y cómo hacer que trabajen juntas**.

Después de todo, incluso Thanos necesitaba reunir las gemas para descubrir lo que podía hacer con todas ellas.
