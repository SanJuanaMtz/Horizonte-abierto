**Estructuras de control: Condicionales**

Tomar decisiones es algo que hacemos todos los días.

Elegimos qué comprar, qué camino tomar o incluso qué decir en cierto momento.

A veces es fácil.

Otras veces, no tanto.

Pero en muchos casos, nuestras decisiones dependen de una condición.

Si pasa algo, actuamos de cierta forma.

Si no pasa, hacemos algo diferente.

---

En programación ocurre lo mismo.

Necesitamos una forma de tomar decisiones dentro de nuestros programas.

Ahí es donde entran las estructuras de control.

Estas nos permiten decidir qué camino seguirá el programa dependiendo de una condición.

---

Una de las más importantes son los **condicionales**.

Nos permiten ejecutar distintos bloques de código según se cumpla (o no) una condición.

---

Por ejemplo, tenemos la estructura `if`.

```python
if condicion:
# código que se ejecuta si la condición es verdadera
```

---

También podemos usar `if-else`, cuando queremos una alternativa:

```python
if condicion:
# si es verdadera
else:
# si es falsa
```

---

Y cuando existen más escenarios, usamos `if-elif-else`:

```python
if condicion:
# primer caso
elif condicion2:
# segundo caso
else:
# caso por defecto
```

---

Cada una de estas estructuras nos permite tomar decisiones más complejas.

Y aunque parecen simples, cambian completamente la forma en la que programamos.

---

Porque a partir de aquí, el programa deja de ser una serie de instrucciones fijas…

y empieza a reaccionar.
